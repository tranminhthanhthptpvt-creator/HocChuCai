# Bé Học Chữ Cái Tiếng Việt (Vietnamese Alphabet Learning App)

Ứng dụng web tương tác trực quan giúp các bé mầm non và học sinh tiểu học nhận diện mặt chữ và phát âm chuẩn 29 chữ cái Tiếng Việt theo chương trình của Bộ Giáo dục & Đào tạo.

## Tính năng nổi bật

- **29 chữ cái Tiếng Việt chuẩn**: `A, Ă, Â, B, C, D, Đ, E, Ê, G, H, I, K, L, M, N, O, Ô, Ơ, P, Q, R, S, T, U, Ư, V, X, Y`.
- **Phát âm chuẩn giọng Tiếng Việt**:
  - **Âm chuẩn (Đánh vần)**: A, Ă, Â, Bờ, Cờ, Dờ, Đờ, E, Ê, Gờ, Hờ, I, Ca, Lờ, Mờ, Nờ, O, Ô, Ơ, Pờ, Quờ, Rờ, Sờ, Tờ, U, Ư, Vờ, Xờ, I.
  - **Tên chữ cái**: A, Á, Ớ, Bê, Xê, Dê, Đê, E, Ê, Giê, Hát, I ngắn, Ca, E-lờ, Em-mờ, En-nờ, O, Ô, Ơ, Pê, Quy, E-rờ, Ét, Tê, U, Ư, Vê, Ích, I dài.
  - **Kèm từ vựng ví dụ minh họa**: Kết hợp hình ảnh emoji và từ vựng sinh động (ví dụ: `Bờ - Quả bóng ⚽`, `Cờ - Con cá 🐟`).
- **Thao tác đơn giản**: Bé chỉ cần chạm vào màn hình hoặc bấm phím bất kỳ để chuyển chữ và nghe phát âm.
- **Nút nghe lại to rõ**: Cho phép bé bấm nghe lại nhiều lần để tự kiểm tra phát âm.
- **Thanh 29 chữ cái tiện lợi**: Nhấp vào bất kỳ chữ cái nào ở cuối trang để xem và nghe ngay chữ đó.
- **Hoạt động đa nền tảng**: Tương thích tốt trên máy tính, điện thoại thông minh, máy tính bảng (iPad/Android).
- **Không cần cài đặt phức tạp**: Chạy trực tiếp trên trình duyệt hoặc deploy lên Vercel / GitHub Pages.

## Cách sử dụng

- **Chuột / Cảm ứng**: Chạm/Click vào màn hình để chuyển chữ cái. Click vào nút `🔊 Nghe phát âm` hoặc từ vựng để nghe lại.
- **Phím tắt**:
  - `Phím cách (Space)` / `Mũi tên phải (→)` / `Enter`: Chữ tiếp theo.
  - `Mũi tên trái (←)`: Chữ trước đó.
  - `Phím R`: Nghe lại chữ hiện tại.
